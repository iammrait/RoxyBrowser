## Qu'est-ce que RoxyBrowser?

RoxyBrowser est une application de gestion de profils de navigateur qui permet de créer des environnements de navigation indépendants. Au lieu de placer chaque session dans un navigateur partagé, il crée des profils séparés.

Chaque profil peut maintenir ses propres:
- Cookies et sessions de connexion
- Cache du navigateur et stockage local
- Connexion proxy
- User agent et profil du système d'exploitation
- Paramètres de langue, fuseau horaire et emplacement
- Configuration Canvas, WebGL, WebRTC et polices
- Favoris et extensions
- Projet, tags et attribution de compte
