## ¿Qué es RoxyBrowser?

RoxyBrowser es una aplicación de gestión de perfiles de navegador que permite crear entornos de navegación independientes. Cada perfil mantiene su propio conjunto de cookies, sesiones, proxy y configuración de huellas digitales.

## Preguntas Frecuentes

**¿RoxyBrowser es gratis?**
¡Sí! 5 perfiles permanentes gratis. Ensayo de 7 días con 10 perfiles disponible.

**¿Funciona en móvil?**
No hay app nativa para Android/iOS. El cliente de escritorio puede simular entornos móviles.

**¿Qué protocolos proxy soporta?**
HTTP, HTTPS, SOCKS5, SSH.

## Uso Responsable

RoxyBrowser no anula las reglas de los sitios web que visitas. Solo gestiona cuentas que posees o estás autorizado a manejar.
