## What is RoxyBrowser?

RoxyBrowser is a desktop browser-profile management application commonly described as an antidetect or fingerprint browser. Instead of placing every session inside one shared browser environment, it creates separate profiles.

Each profile can maintain its own:
- Cookies and login sessions
- Browser cache and local storage
- Proxy connection
- User agent and operating-system profile
- Language, time-zone and location settings
- Canvas, WebGL, WebRTC and font configuration
- Bookmarks and extensions
- Project, tag and account assignment

This separation can help with legitimate workflows such as client-authorized social media management, regional e-commerce operations, website localization and quality-assurance testing, separate work environments, approved affiliate projects and controlled team access.

## Browser Profiles

### What are Profiles?

A profile is an independent browser environment. It stores browsing data and configuration for that session. It is not a complete virtual machine, but its browser-level data is separated from other profiles.

### Naming Best Practices

Use descriptive names:
- `Client-A-Canada-Support`
- `Store-US-Customer-Service`
- `QA-French-Checkout`
- `Marketing-EU-Ads`

Avoid generic names like "Profile 1" — they become difficult to manage as your list grows.

### Projects and Tags

- **Projects** group related profiles by client, region, department, or purpose
- **Tags** add filtering layers: country, platform, owner, status, or testing purpose

### Creating a Profile

1. **Profile name** — Choose a descriptive naming format
2. **Project and tags** — Assign to the appropriate workflow
3. **Browser engine and OS** — Select based on your requirements
4. **Proxy** — Add connection if needed
5. **Language, time zone, location** — Match the proxy IP
6. **Media** — Choose image/video/sound loading preferences

### Advanced Fingerprint Settings

Advanced options include:
- Canvas
- WebGL
- WebRTC
- Screen resolution
- Fonts
- Hardware information
- User agent
- Media devices

> ⚠️ Most users should keep automatically generated defaults. Random combinations can produce inconsistent profiles (e.g., mobile user agent with desktop hardware).

### Profile Templates

Templates save time when creating similar profiles. They do NOT save:
- Proxies
- Credentials
- Cookies
- Projects
- Tags
- Notes

RoxyBrowser can create up to 100 profiles in batch and import up to 500 profiles at once.

## Proxy Configuration

RoxyBrowser supports:
- HTTP
- HTTPS
- SOCKS5
- SSH
- IPv4/IPv6
- Username/password authentication
- Dynamic proxies with refresh URLs

### Adding a Proxy

**Manual Addition:**
1. Open Proxies area or profile creator
2. Choose IPv4 or IPv6
3. Select correct protocol
4. Enter host, port, username, password
5. Add refresh URL for dynamic proxies
6. Click "Test Proxy"
7. Save after successful test

> ⚠️ Protocol must match your provider. Don't label everything as SOCKS5.

**Batch Addition:**
1. Choose batch-add option
2. Paste one proxy per line
3. Enable duplicate removal
4. Click "Parse"
5. Review recognized fields
6. Click "Test All"
7. Correct or remove failed entries
8. Save working proxies

### Proxy Format

```
host:port:username:password
```

### Troubleshooting

- Check proxy expiration
- Verify protocol, host, port, credentials
- Confirm IP whitelisting if required
- Check for firewall/VPN interference
- Try different IP detection channel

## Window Sync (Windows)

Window Sync mirrors actions from one main profile to controlled profiles. Currently Windows-only.

### Starting Synchronization

1. Open the profiles to coordinate
2. Select "Synchronizer"
3. Choose participating profiles
4. Assign one as main window
5. Confirm controlled windows
6. Click "Start Sync"
7. Review layout before actions

The main window:
- Placed top-left by default
- Identified by blue border

### Sync Controls

- Mouse and keyboard synchronization
- Same-text or profile-specific input
- Random-number input
- Open URLs across profiles
- Tab controls
- Grid, stack, custom layouts
- Pause, resume, timing delays

## FAQ

**Is RoxyBrowser free?**
Yes! 5 permanent profiles free. One-time 7-day trial with 10 profiles available.

**Does it include free proxies?**
No. Proxy services are separate from profile allowances.

**Does it work on mobile?**
No native Android/iOS app. Desktop can simulate mobile browser environments.

**Which proxy protocols?**
HTTP, HTTPS, SOCKS5, SSH.

**Can it guarantee no bans?**
No. No browser or proxy can guarantee this. Restrictions come from content, behavior, payment, identity, and other signals.

**Can cookies be imported?**
Yes, but cookies are authentication data. Only import for accounts you own or are authorized to manage.

**Is SOCKS5 required?**
No. Select the protocol your provider actually supplies.
